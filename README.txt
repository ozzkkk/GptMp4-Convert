FILM DÖNÜŞTÜRÜCÜ V12.0

Düzeltmeler:
- Dosyalardan video seç alanında görünmez/çok küçük input yerine, gerçek file input butonun tamamını kaplayacak şekilde yerleştirildi. Android dosya seçicisini doğrudan açar.
- Dosya seçicide video türleri filtrelenir ve çoklu seçim açıktır.
- Klasör seç ve Dosyalardan video seç kontrolleri her ekranda yan yana ve eşit genişlikte tutulur.
- Başlığın sağındaki Yerel işlem yazısı V12.0 olarak değiştirildi; aynı yazı stili korunur.
- Uygulama JS adresi ve Service Worker önbelleği V12 olarak yükseltildi; eski cache sürümleri aktivasyonda silinir.

GitHub deposunun ana dizininde ZIP içindeki dosyaları eskilerin üzerine yükle:
index.html, app.js, style.css, manifest.webmanifest, sw.js, worker.js, icon.svg, README.txt.

Not: Dosya seçici sistem arayüzünü Android/Chrome açar. Dosya seçimi gerçekleştiğinde video olmayan içerikler uygulama listesine eklenmez.
